# Rizki Adhatilla Yusa | Portfolio

Personal portfolio website built with React, TypeScript, Vite, Tailwind CSS, Framer Motion, and Lightswind UI.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Personalization notes

- Update the initials avatar in `src/components/HeroSection/HeroSection.tsx` if you want to use a personal photo.
- Update contact details and project links in the relevant section components when those details change.
- The CV file is available in `public/CV_RizkiAdhatillaYusa.docx` and linked from the hero section.

## Deployment

The project can be deployed to Vercel using the default Vite settings:
- Build command: `npm run build`
- Output directory: `dist`
