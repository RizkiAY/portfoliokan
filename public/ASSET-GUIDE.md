# Portfolio image setup

## Profile photo on the Hero business card
Add your portrait photo as `public/profile.jpg`. A square or portrait image works best; it is cropped into a circle automatically. If the file is not present, the card shows the `RY` initials.

## Featured Project screenshots
Add screenshots to `public/project-screenshots/` using the filenames listed in `public/project-screenshots/README.md`. Each project card will show its screenshot in the left preview area. If a screenshot is missing, a designed preview placeholder appears instead.
